# 项目目录规范（2026-09-08）

## 基准原则

Jetson `/home/nvidia/calibration` 当前测试版是 demo 运行基准；Windows 目录是整理版、镜像和备份。除非明确确认，不要用 Windows 旧文件覆盖 Jetson 测试版。

## 顶层目录

- `00_项目说明文档`：总说明、v3 详细说明、入口命令。
- `01_标定数据`：标定图片、角点图、samples、外参结果、求解日志。
- `02_固定标定位姿`：固定标定位姿和复现脚本。
- `03_手柄控制_xbox`：Xbox 控制代码和配置。
- `04_机械臂网关_arm_gateway`：ArmGateway 代码、配置和可执行文件。
- `05_机械臂SDK_ROS_源码`：机械臂 SDK 与 ROS2 相关源码。
- `06_历史参考_legacy`：历史参考资料、旧 Jetson 备份、归档的散落目录。
- `07_夹爪CTAG2F120`：夹爪 SDK 与控制脚本。
- `08_v3单步抓水瓶测试`：当前抓水瓶闭环程序和运行资料。
- `09_辅助工具_tools`：Windows 辅助工具，例如 Jetson 连接、ROI 工具。
- `99_原始备份包`：原始压缩包和 manifest。
