## 3. 当前尚未完成 / 已知限制

原“尚未下降夹取、尚未验证夹取提升、尚未验证放置位/占位、尚未闭环”等项已通过下面的“抓取-放置整链 Demo”完成逐段验证（见 6.x）。仍存在的问题：

- 每段长 MoveBlend 途中存在**固定冻结点**（误差值长时间不变后瞬间到位；同一段多次跑动冻结点位置一致），尚未从控制器侧消除。
- 长 MoveBlend 结束后网关可能掉为 `RECONNECTING` 或 `CONNECTED + disabled`，下次运动前需一次 Clear+Enable（“上电声”）。Python 侧已把重复补发节流为最多一次，控制器“运动后自动掉使能”仍需控制器侧参数才能彻底避免。
- MoveBlend 速度档上限为 `v10`；`v12 / v15 / v20` 均被控制器拒绝（rc=-2）。
- S2 的 YOLO 在视觉链路刚启动约 40 s 内不稳定，识别可能需重试 1~2 次。
- 放置位“占用 → X?10 cm”是**固定单次偏移**，若该偏移位也有瓶不会继续递增避让。

下一阶段不能直接恢复旧闭环程序，应继续按“单段执行、现场确认、记录安全点位”的方式完成。

## 6. 抓取-放置整链 Demo（bottle_pick_place_demo_v3）已完成状态与流程

更新时间：2026-09-07。本阶段目标是完整闭环演示：**抓取拍照位启动 → 识别水瓶 → 经瓶上方到抓取位 → 夹爪合 → 到放置拍照位 → 检测放置区 → 空则放到示教位 / 占用则放到 X?10 cm 偏移位 → 回到抓取拍照位**。已通过多轮真实运行验证。

### 6.1 完整流程（S1~S8）

| 步骤 | 内容 | 说明 |
| --- | --- | --- |
| S1 | 回抓取拍照位 | MoveBlend，终点停靠，到位误差约 0.1~0.2 mm |
| S2 | 识别水瓶 | YOLOv8 class39 + 固定拍照位手眼换算 + 深度补偿；15 帧稳定得瓶基座坐标 |
| S2.5 | 夹爪张开 | 确保抓取前夹爪全开 |
| S3 | 经“瓶上方”点 | 中途点（XY 来自识别补偿，Z=抓取示教 Z+0.15 m，姿态不变），一次 MoveBlend 途经不下停 |
| S4 | 到抓取位 | 终点停靠：XY=示教抓取 XY + 识别偏差补偿，Z=示教 Z + 偏差 + **?1 cm**；到位后停稳 0.6 s（`dwell_still`）→ 夹爪合（力 60）→ 再停稳 0.3 s → 才启动下一步 |
| S5 | 带瓶到放置拍照位 | 经瓶上方高位横移，避免擦碰 |
| S6 | 放置区检测 | 只认图像左半幅 ROI（`check_roi_norm=[0,0,0.5,1]`），ROI 内连续 3 帧出现瓶框 → occupied |
| S7 | 放置 | 空 → 示教放置位；占用 → 放置位 **X?10 cm** 偏移。先经放置中途点途经，到点张开夹爪 |
| S8 | 回到抓取拍照位 | 直接长程回位（不再绕抓取区上方） |

正常结束退出码 `0`；任一步失败抛出异常并释放网关控制权（退出码非 0）。

### 6.2 关键行为与参数

- **手眼补偿**：示教时记录参考检测点 `ref_detection_xyz`（当前 (0.8252, 0.2468, 0.4516)）；运行时抓取目标 = 示教抓取点 + (本次检测 ? 参考检测)，即跟随瓶身移动，Z 额外 ?0.01 m（`GRASP_Z_EXTRA_M`）。
- **MoveBlend 途经点**：每一腿只 `first_insert + 多条 insert_line + 一次 start`，途经点不停、只停最后一个目标；速度档 `v10`（控制器上限，v12/v15/v20 均被拒）。
- **到位判据**：对实时位姿与最后目标求距离，≤3 mm 视为到位。
- **与 Xbox 共存**：程序只在运动前认领网关 owner（`AUTO_TASK`），结束 `release_owner`；运行期间不碰手柄即可，无需反复启停 Xbox 进程。
- **使能节流**：长 MoveBlend 后网关可能 `RECONNECTING` / `CONNECTED+disabled`；`ensure_ready` 只每 5 s 试探恢复、READY 后补一次 enable，避免在停靠点连续 Clear+Enable。
- 抓取侧点位 XY 来自识别（可适应瓶位变化），Z/姿态来自示教 JSON；放置侧点位固定来自示教 JSON。
